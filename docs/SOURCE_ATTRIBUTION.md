# Source attribution

The active repository is HimVote. The existing HimVote implementation and documentation were already present in the Team Rocket workspace before the SecureVote reconciliation pass.

The requested Helios, Belenios, and ElectChain archives were not present. No source files from those projects were copied, linked, or modified during this pass. Their licenses and security findings therefore remain unreviewed in this workspace.

The current implementation uses its own service boundaries and protocol fixtures. The election engine adapter is explicitly marked as a development stand in. It must not be described as Helios, Belenios, ElectionGuard, or another official engine.

When reference archives are supplied, record each archive SHA256, upstream version, license, reused file path, and required notices before importing any code. Prefer an external process boundary for a copyleft engine when license and protocol review are incomplete.
