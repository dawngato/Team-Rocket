# ADR engine choice

Status: blocked pending external engine evidence

The repository does not contain the requested Helios, Belenios, or ElectChain archives. ElectionGuard is not pinned or installed. Therefore no external engine choice can be claimed.

Profile VEEM is retained only as a local development adapter. Its local proofs exercise service boundaries and test vectors, but it is not an official implementation and has no independently supplied verifier. It is not eligible for a production secret ballot claim.

The next engine review must record immutable version, license, maintenance state, supported booth, native export, native verifier command, revoting semantics, trustee model, roster integration, accessibility, and mutation failure evidence. A one cast policy cannot be implemented by hiding a UI control.
